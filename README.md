# SmartApps Update

Repositorio público de instaladores y canales de actualización de las aplicaciones SmartApps.

## Canales estables

| Aplicación | Etiqueta de publicación |
| --- | --- |
| SmartFix | `smartfix-latest` |
| Smart Kids Boutique | `smartkids-latest` |
| Smart Print para Windows | `smartprint-windows-latest` |
| Smart Print para Android | `smartprint-android-latest` |

Cada canal conserva una publicación estable y reemplaza sus instaladores al lanzar una versión nueva. Las claves privadas de firma no se guardan en este repositorio.
